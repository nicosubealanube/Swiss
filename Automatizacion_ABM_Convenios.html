Automatización ABM de Convenios

Casilla: ABM.Convenios@swissmedical.com.ar → Excel en SharePoint

🔒 Ejecución 100% Local y Privada

Automatización 100% Interna en Microsoft 365 (Outlook → SharePoint Excel)

Con esta configuración, cada vez que ingresa un correo con un formulario PDF a ABM.Convenios@swissmedical.com.ar, los datos se cargan automáticamente en el Excel de SharePoint dentro del entorno corporativo de Microsoft 365, sin pasar por servidores externos.

Paso 1 (En Excel)

Cargar el Script Extractor en el Excel de SharePoint

Este script interno de Excel lee el correo y el formulario PDF adjunto y escribe la nueva fila en la planilla:

  1. Abrí en tu navegador el archivo Excel en SharePoint donde se registran las excepciones.
  2. En el menú superior del Excel, hacé clic en la pestaña Automatizar (Automate) y seleccioná Nuevo script (New Script).
  3. En el panel de código que se abre a la derecha, borrá el contenido inicial.
  4. Hacé clic en el botón verde para copiar el script y pegalo en el panel con Ctrl + V: 
    
              
    5. 
              
  5. 
                Nombrá el script como CargarExcepcionABM y hacé clic en
                Guardar script (Save script).
              
    6. 
            

          


          
          

            

              Paso 2 (En Power Automate)
              
Vincular la casilla ABM.Convenios con el Excel

            

            

              Regla automática dentro de Microsoft 365 para que cada email entrante dispare el script del Excel:
            

            
    
              
  1. 
                Ingresá a
                make.powerautomate.com
                con tu cuenta corporativa de Swiss Medical.
              
    2. 
              
  2. 
                En el menú izquierdo seleccioná Crear →
                Flujo de nube automatizado.
              
    3. 
              
  3. 
                Asignale el nombre ABM Convenios a Excel, buscá el disparador
                "Cuando llega un correo electrónico nuevo a un buzón compartido (V2)" (Office 365 Outlook) y presioná Crear.
              
    4. 
              
  4. 
                Configurá el bloque del correo con:
                
      
                  
    • Dirección del buzón original: ABM.Convenios@swissmedical.com.ar
      • 
                  
    • Carpeta: Inbox
      • 
                  
    • Incluir datos adjuntos: Sí
      • 
                  
    • Solo con datos adjuntos: Sí
      • 
                
    
              
    5. 
              
  5. 
                Agregá un (+) Nuevo paso, elegí Excel Online (Empresas) y seleccioná la acción
                "Ejecutar script" (Run script).
              
    6. 
              
  6. 
                Seleccioná el archivo Excel de Excepciones en SharePoint y elegí el script CargarExcepcionABM.
              
    7. 
              
  7. 
                Completá los 3 parámetros con el contenido dinámico del correo:
                
      
                  
    • emailBody: Cuerpo (Body) del correo.
      • 
                  
    • receivedDate: Hora de recepción (Received Time).
      • 
                  
    • pdfBase64: Contenido de datos adjuntos (Attachments Content).
      • 
                
    
              
    8. 
              
  8. 
                Hacé clic en Guardar. A partir de ese momento, cada correo nuevo se procesará automáticamente.
              
    9.
